# 🛡️ Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover any security vulnerability (especially regarding token generation, cookie leaks, or rate-limiting bypasses), please report it responsibly:

1. **Do NOT open a public GitHub Issue.**
2. Send an email or private message to the repository maintainer.
3. Include detailed steps to reproduce the issue.

We appreciate your efforts in keeping this project secure.
